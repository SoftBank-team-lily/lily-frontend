# Lily

Next.js App Router 기반 랜딩 페이지입니다.

## 개발

Node.js 24 이상과 pnpm 12.8.1을 사용합니다.

```sh
corepack enable
pnpm install
pnpm dev
```

개발 서버: http://localhost:3000

## 검사

```sh
pnpm build
pnpm lint
pnpm typecheck
pnpm test
```

`pnpm test:watch`로 단위·컴포넌트 테스트를 감시 모드로 실행합니다.
